## 1. 功能概述
AI 面试平台前端：Vue 3 SPA，6 个页面挂在 Layout 侧边栏下，无登录。通过 Vite 代理 `/api` → `localhost:8080` 与后端通信。

├── style.css            # 全局 reset

技术栈：Vue 3.5.40（`<script setup>`、纯 JS 无 TS）+ Element Plus 2.14.3（全量注册）+ vue-router 4.6.4 + axios + marked 18（Markdown 渲染）+ spark-md5。无 Pinia（全组件内 state）、无 lint/测试。

## 3. 核心流程（约定与模式）
- **HTTP 约定**：所有业务接口走 `src/api/` 模块 + axios 拦截器；拦截器已把 `Result<T>` 解包，所以 `.then(r => r.data)`。**例外**：RAG/会话 5 个接口在 KnowledgePage.vue 内裸 fetch（SSE 流式 + 会话 CRUD），手动解析 `data:` 行与 Result 信封。
- **SSE 消费**：`fetch` → `resp.body.getReader()` + TextDecoder 按行拆 `data:` 前缀拼接（KnowledgePage.doChat）。
- **状态轮询**：简历列表、面试评估均轮询（面试 3s），页面卸载时清理定时器。
- **启动**：`cd frontend` 后 `pnpm dev` → 5173 端口；构建 `pnpm build` → dist/（.gitignore 已排除，不入库）。
- **路由**：hash 模式（`createWebHashHistory`）。
