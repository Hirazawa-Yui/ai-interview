## 1. 功能概述
AI 面试平台前端：Vue 3 SPA，6 个页面挂在 Layout 侧边栏下，无登录。通过 Vite 代理 `/api` → `localhost:8080` 与后端通信。

## 3. 核心流程（约定与模式）
- **HTTP 约定**：所有业务接口走 `src/api/` 模块 + axios 拦截器；拦截器已把 `Result<T>` 解包，所以 `.then(r => r.data)`。**SSE 例外（T8 起收敛）**：流式接口因拦截器假设 Result JSON（且 axios 会缓冲整个流），由 `api/rag-chat.js` 的 `ragChatApi.streamChat` 在 api 层封装裸 fetch——resp.ok 检查（非 2xx 取业务 message 抛错）、逐行 `data:` 解析 onData 回调、AbortSignal 支持；页面层不再出现裸 fetch（原 KnowledgePage 5 处已收敛）。
- **SSE 消费**：`ragChatApi.streamChat` → 内部 `resp.body.getReader()` + TextDecoder 按行拆 `data:` 前缀逐行回调（页面不再手写解析）。
- **状态轮询**：简历列表、面试评估均轮询（面试 3s），页面卸载时清理定时器。
- **启动**：`cd frontend` 后 `pnpm dev` → 5173 端口；构建 `pnpm build` → dist/（.gitignore 已排除，不入库）。
- **路由**：hash 模式（`createWebHashHistory`）。

## 4.5 样式体系（T16，2026-09-08）
- **Notion 浅色产品风**（参考 `docs/design/DESIGN.md` spec 适配）：三层纯 CSS 变量，无 sass——`styles/notion-tokens.css`（--nt-* 原始 token）→ `styles/el-plus-overrides.css`（--el-* 换肤：主色紫 #5645d4 全档 + 语义/灰阶 + hairline 边框 + 圆角 8px + 扁平卡片）→ `style.css`（body 底色/字体/h1 排版）
