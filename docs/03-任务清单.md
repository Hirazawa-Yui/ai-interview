## 2. 验收方式（用户已确认 2026-09-05）

1. **Claude 自动验收**：启动前后端，用 Swagger/curl/浏览器走核心链路，把证据写入对应任务的验收记录节
2. **用户复核**：Claude 给出页面操作路径，用户亲自确认
3. **提交**：用户确认通过后，Claude 给出 git 提交命令（**由用户手动执行**），同时可开始下一任务；每次提交只含一个任务
4. 提交格式约定：`<type>: <任务名>`（中文），如 `feat: T9 面试日程`
